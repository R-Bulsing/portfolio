Hi! Ik ben Rianne Bulsing

Welkom op mijn portfolio! Ik ben 19 jaar en tweedejaars Creative Software Developer aan het Grafisch Lyceum in Rotterdam.

Ik maak graag digitale projecten, van websites tot apps, en vind het leuk om creatieve en technische oplossingen te combineren.

Bekijk vooral mijn projecten en ontdek waar ik trots op ben!

Bekijk hier mijn projecten

Volume 75

Extern project voor het 75-jarig jubileum van het Grafisch Lyceum, met een teaser van het feest. We hebben gewerkt met HTML, CSS, JavaScript en PHP. Ondanks uitdagingen in de taakverdeling door vertrek van de groepsoprichter, hebben we dankzij goede samenwerking het project succesvol afgerond.

Windows95

Project tijdens de Make-a-thon 2024 met het thema retro. We maakten een namaakversie van Windows 95 met retrogames, waaronder de Snake-game die ik ontwikkelde. Gemaakt met HTML, CSS, JavaScript en 95.css. Dankzij goede samenwerking werd ons team eerste van de eerstejaars.

Quizzy

Derde beroepsproject: een quizsite met leerzame thema’s. Wij kozen Mediawijsheid en maakten per subthema een eigen quiz. Gemaakt met HTML, CSS en JavaScript. Ondanks een conflict in de groep hebben we het project succesvol afgerond en een mooie website neergezet.
